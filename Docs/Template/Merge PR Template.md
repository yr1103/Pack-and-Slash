# Merge Pull Request Template

> `main-develop` → `main` 병합 시 Github Pull Request에 등록할 양식
>
> 사용자의 명시적인 명령 외에는 해당 양식을 기반으로 PR을 작성한다.
>
> 작성 규칙은 `Docs\Documentation\GithubPullRequestRules.md`의 `4. Merge PR 작성 규칙`을 따른다.



```markdown
# [Merge] 개발 단계명

## 개발 단계

- 단계 : (예 : 최소 단위 프로토타입)

## 주요 변경 사항

- (변경 내용) (#PR번호)

## 확인 사항

- [ ] `main-develop`에서 컴파일 에러, Error, Warning 로그가 발생하지 않는다.
- [ ] 단계 목표 기능이 정상 동작한다.

## 리뷰어에게 전달할 주의사항

-

## 연결 Issue

- Closes #
```
