# Boss Spec

> 중간 보스·최종 보스 등장과 클리어 조건.
> 관련 GDD : §13

---

## 계약

- 중간 보스는 **5분 / 10분 / 15분**에 자동 등장하고, 처치하면 **4칸 확장 선택권**을 지급한다. (확장 판정은 `Inventory.md`)
- 중간 보스 처치 시 경험치 보석 없이 **보물상자만** 드랍한다. 플레이어가 상자에 접촉하면 획득하며, 화면 흐름은 `GameFlow.md`, 보상 처리는 `Reward.md`의 `보물상자 보상`을 따른다.
- 보스의 등록·이동은 일반 몬스터와 동일하다. (`MonsterMovement.md`)
- 중간 보스 패턴은 **5분 돌진 / 10분 짧은 직선 공격 / 15분 퍼지는 탄환 공격**으로 확정한다.
- 최종 보스는 **20분**에 등장하며, 처치하거나 등장 이후 **90초 생존** 시 클리어한다.
- 최종 보스 패턴은 **일정 간격 돌진 + 퍼지는 탄환 공격**이며, 탄환은 15분 보스와 발사 궤적이 다르다. 구체 궤적은 보스 작업 브리핑에서 결정한다.
- 최종 보스 등장 이후에도 일반 몬스터는 계속 생성된다.
- 이전 보스를 처치하지 못했어도 다음 보스(중간·최종 모두)는 정해진 시간에 그대로 등장한다. 중간 보스는 5분 내에 처치되도록 밸런스로 유도한다.
- 보스 등장 사전 알림/카운트다운 UI는 구현하지 않는다.

## 테스트 기준

- **보스:** 5·10·15분 보스 등장, 처치 시 보물상자 드랍 및 접촉 획득, 20분 최종 보스 등장, 처치 또는 90초 생존 클리어
