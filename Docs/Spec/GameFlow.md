# Game Flow Spec

> 게임 상태 전환, 레벨업·보물상자 일시정지, 연속 레벨업 회차 처리.
> 관련 GDD : §2, §9.1, §9.5, §13.1

---

## 데이터

| 데이터 범주 | 최소 필요 정보 | 사용처 |
|---|---|---|
| 레벨업 대기 상태 | 처리할 회차 수 또는 큐, 현재 회차, 해당 회차 선택 수 | 연속 레벨업 순차 처리 |

## 계약

### 게임 상태
- 최소한 **캐릭터 선택 / 전투 / 레벨업·인벤토리 정리 / 보물상자 보상·인벤토리 정리 / 클리어 / 게임 오버**를 구분한다.

### 보물상자 일시정지
- 중간 보스의 보물상자를 획득하면 레벨업과 동일하게 전투를 일시정지하고 보상·장착 인벤토리·좌측 Storage UI를 표시한다.
- 보물상자 화면은 레벨업 화면에 **4칸 확장 선택**이 추가되고, 보상은 **5중 최대 3택**이다. (보상 규칙은 `Reward.md`, 확장은 `Inventory.md`)
- `완료` 조건은 레벨업 회차와 동일하다.
- 처리 대기 중인 레벨업 회차가 있으면 **레벨업 회차를 모두 먼저 처리**한 뒤 보물상자 화면을 표시한다.

### 레벨업 일시정지
- 경험치 지급 결과 레벨업 조건을 충족하면 전투를 일시정지하고 보상·장착 인벤토리·좌측 Storage UI를 표시한다.
- 레벨업 중에는 몬스터 이동·공격, 투사체, 경험치 보석의 월드 동작, 보스 출현, 생존 타이머가 진행되지 않는다.
- 인벤토리 드래그·회전·버튼 입력과 UI 애니메이션은 일시정지 상태에서도 동작한다.
- 시간 일시정지/복구의 소유자는 하나의 게임 진행 시스템으로 한정한다. `Time.timeScale` 사용 여부 및 UI Unscaled Time 적용 범위는 구현 브리핑에서 결정한다.

### 회차와 완료
- 한 회차는 `후보 3개 표시 → 획득·판매·리롤·진화·보관 및 정리 → 완료`로 구성한다. (보상 규칙은 `Reward.md`)
- `완료`는 아래를 모두 만족할 때만 허용한다.
    - Storage 수량 5개 이하 (`Inventory.md`)
    - 장착 격자 배치 유효, 미처리 드래그 없음
    - 현재 회차의 보상 선택 상태 유효
- 보상·판매·합성·소비형 효과에 의한 상태 갱신은 회차별로 **중복 실행 없이 한 번만** 확정한다.

### 연속 레벨업
- 대기 회차가 있으면 현재 회차 `완료` 후 **새 레벨업 효과음 + 새 보상 UI + 새 후보 3개**를 표시한다.
- 각 회차의 2개 획득 한도와 슬롯 상태는 독립적이다.
- **마지막 회차가 완료될 때까지 전투·생존 타이머를 재개하지 않는다.**

## 테스트 기준

- **게임 상태:** 레벨업 중 생존 시간 및 월드 일시정지, 완료 시 복구
- **보물상자:** 상자 획득 시 일시정지, 4칸 확장 선택 + 5중 최대 3택, 레벨업 대기 회차가 있으면 레벨업 우선 처리 후 상자 화면 표시
- **연속 레벨업:** 2회 이상 조건 동시 충족, 첫 회차 `완료` 후 두 번째 효과음/UI/후보 3개 재생성, 회차별 2개 획득 제한, 모든 회차 처리 전 월드 타이머 정지 유지

## 미정 파라미터

- 누적 레벨업 판정 및 상태 전이 구현 방식(큐/카운터 등), 현재 회차 데이터 수명 관리
