# Reward Spec

> 레벨업 보상 후보, 판매·리롤, 소비형 보상, 특수 재화.
> 관련 GDD : §9.2 ~ §9.4, §11

---

## 데이터

| 데이터 범주 | 최소 필요 정보 | 사용처 |
|---|---|---|
| 보상 슬롯 | 후보 종류(장착형/소비형/확장권), 미처리/획득/판매 상태, 회차 ID | 3중 최대 2택, 잔여 슬롯 리롤 |
| 경제 상태 | 특수 재화, 판매가, 리롤 비용, 진화 비용 | 진화·리롤 |

## 계약

### 획득
- 회차별 후보 3개에서 **최대 2개 획득**. 0·1개만 획득해도 완료할 수 있다.
- 슬롯 상태는 **미처리 / 획득 / 판매**를 구분하며, 회차 간 슬롯 상태가 섞이지 않는다. 소비형·확장권 보상도 획득 수에 포함한다.

### 보물상자 보상
- 중간 보스가 드랍한 보물상자(`Boss.md`)를 획득하면 후보 **5개 중 최대 3개**를 획득한다. 화면 흐름은 `GameFlow.md`의 `보물상자 일시정지`를 따른다.
- 후보에는 레벨업 보상과 같이 소비형·확장권 등이 등장한다.
- 후보 중 **Lv.2 장비 1개를 무작위로 확정 등장**시킨다.
- 15분 보스 상자의 확정 장비를 Lv.3으로 올릴지는 밸런스 단계에서 결정한다.
- 판매·리롤 규칙은 레벨업 보상과 동일하게 적용하는 것을 전제로 하며, Roadmap 13단계 브리핑에서 확정한다.

### 판매·리롤
- 획득하지 않은 보상은 판매할 수 있다. **판매한 슬롯은 소멸**하며 리롤 후보로 다시 포함되지 않는다.
- 리롤은 미처리 슬롯만 다시 추첨한다. 획득·판매한 슬롯은 제외하며, 남은 후보가 없으면 리롤할 수 없다.
- 장착 아이템과 Storage 아이템의 판매는 인스턴스 제거와 특수 재화 증가를 동반한다.
- 캐릭터 필수 아이템의 판매/장착 해제 조건과 경고 UI는 게임 규칙 확정 전까지 추가하지 않는다.

### 특수 재화
- 판매, 별도 처치 조건 등으로 얻고 리롤과 진화에 소비한다. 가격과 지급량은 설정 가능한 밸런스 값이다.

### 후보 종류
- **1칸 확장권:** 약 5%의 초기 확률로 등장한다. 적용 시 셀 확장(`Inventory.md`)과 연동한다.
- **소비형:** 선택 즉시 효과를 반영하고 장착 인벤토리·Storage에 등록하지 않는다. 획득 완료 상태를 기록해 버튼 재입력·화면 재표시 시 중복 적용을 막는다.
    - HP +30 회복은 MVP 예시다.
    - 맵 전체 경험치 보석 수집은 추가 구현 후보다. 선택 시 보석을 정상 수집 경로(`Combat.md`)로 유도하고, 다중 레벨업은 회차 계약(`GameFlow.md`)을 따른다.
- **상위 레벨:** Lv.1을 기본으로 한다. 상위 레벨 후보는 미등장 또는 극저확률만 검토한다.
- **무기 제외:** 무기가 진화하면 해당 종류의 일반 무기를 후보에서 제외한다. 진화 전 Lv.5 보유 시 등장 허용 여부 등 후보 필터는 보상 생성 계약에서 확정 후 구현한다.

## 테스트 기준

- **보상:** 회차별 0~2개 획득, 보물상자 5중 최대 3개 획득, 판매된 슬롯 리롤 제외, 잔여 슬롯 리롤, 소비형 보상 선택 즉시 적용 및 재적용 방지, 후보 소진 시 완료

## 미정 파라미터

- 상위 레벨 아이템의 희귀 등장 여부/확률
- 소비형 HP 회복 최대치 처리와 후보 등장 조건
- 아이템 판매 가격, 리롤/진화 비용
- 15분 보스 보물상자의 확정 장비 레벨(Lv.2 / Lv.3)
