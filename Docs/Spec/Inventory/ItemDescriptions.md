# 인벤토리 아이템 설명

현재 인벤토리 에셋 14개 중 소모품 2종(`ExpansionTicket`·`HealthPack`)을 제외한 12종에 사용할 한국어 툴팁 문구다. 수치 열의 **기획 초기값**, **테스트값**, **설계 제안**, **에셋 임시값**, **확정 수치**(이슈 #40 확정, 플레이 테스트 후 조절 가능)는 각 출처의 상태를 따른다. 문서에 값이 정해지지 않은 항목은 `지정 수치 없음`으로 표시했다. 점유 칸 수는 인벤토리 에셋의 도형을 기준으로 한다. ## 효과 적용 기준

- 인벤토리 구체화 초안 기준으로 패시브는 상하좌우로 닿은 일반·진화 무기에 적용한다. Lv.3 전역 효과는 장착하면 인접 여부와 관계없이 발동하며 Lv.4~5에서도 같은 수치를 유지한다. 발사 간격 감소 합계 50%, 무작위 탄퍼짐 감소 합계 70%, 이동속도 보너스 총합 +50%는 테스트 상한이다. [인벤토리 구체화 초안 §5](Inventory_System_구체화_초안_v2.md)
- 진화하려면 해당 무기와 대응 패시브를 모두 Lv.5로 올린 뒤 장착 격자에서 맞닿게 배치하고 특수 재화를 지불한다. 재료 두 개를 소비하며, 특수 재화 4개는 테스트 비용이다. [GDD §6](../GDD.md), [인벤토리 구체화 초안 §6](Inventory_System_구체화_초안_v2.md)
- 캐릭터 효과는 두 층이다. **캐릭터 특성**은 고유 아이템 탈착과 무관하게 항상 적용하고, 그 위에 고유 아이템의 **장착 효과**(장착 중) 또는 **해제 효과**(해제 중) 중 하나만 더한다. 캐릭터별 특성과 수치는 아래 `캐릭터별 특성·고유 아이템 효과`의 확정 수치를 따른다. 공격력은 무기 레벨 배율 × (1 + 탄띠 인접 합계) × (1 + 캐릭터 특성)으로 따로 곱한다. 정확도(탄퍼짐 감소)는 냉각기 인접·캐릭터 정확도·무기 Lv.3 감소를 합산해 상한 0.7을 적용한 뒤 탄퍼짐 각도 × (1 − 합계)로 1회 적용한다. 이동속도는 패시브 Lv.3·캐릭터 특성·해제 효과를 합산해 상한 +50%를 적용한다. 프로틴 셰이크는 현재 에셋 이름이며, GDD는 헤비거너 고유 아이템의 최종 종류를 미정으로 둔다. [GDD §3·§19](../GDD.md), [무기 상세 §3.6·§5.3](../Weapon/WeaponSystem.md)

기본 무기와 진화 공격의 기획 수치는 GDD와 무기 상세에서, 기본 무기 에셋 임시값은 무기 기술 문서와 ScriptableObject에서 확인했다. [GDD §4·§6](../GDD.md), [무기 상세 §2·§5·§11](../Weapon/WeaponSystem.md), [무기 기술 문서](../../TechDocs/Weapon.md), [무기 에셋](../../../Assets/Data/Weapon)

# 캐릭터별 특성·고유 아이템 효과

아래 수치는 **확정 수치(2026-11-26, 이슈 #40)**이며 플레이 테스트 후 조절할 수 있다. 캐릭터 특성은 고유 아이템 탈착과 무관하게 항상 적용하고, 장착 효과와 해제 효과는 고유 아이템 상태에 따라 하나만 적용한다.

## 1. 카우보이 — 카우보이 모자

**아이템 설명**

"카우보이의 자존심이 담긴 모자. 모자를 쓰고 있을 때는 침착하고 정확하게 사격하지만, 모자를 벗으면 이성을 잃고 총을 난사하기 시작한다."

**캐릭터 특성 (항상)**
- 권총 공격력 +10%

**장착 효과**
- 없음. 툴팁 문구 : "[장착 효과: 없음] 대신 거울을 볼 때마다 입꼬리가 올라가는 패시브가 발동합니다."

**해제 효과 — 무법자의 난사**
- 권총 공격속도 +60%
- 권총 탄환의 전체 확산각 70° (조준 방향 기준 ±35°, 냉각기 인접 등 탄퍼짐 감소 적용 전 기준값)

**플레이 스타일**

모자를 벗으면 정확한 사격을 포기하는 대신 빠른 연사로 적을 공격한다. 근거리에서는 강력하지만, 거리가 멀어질수록 명중률이 크게 떨어진다.

---

## 2. 겁쟁이 — 전투 조끼

**아이템 설명**

"겁이 많은 생존자가 안전을 위해 착용한 두꺼운 전투 조끼. 조끼를 벗으면 몸이 가벼워져 도망치는 속도는 빨라지지만, 공격을 버틸 자신도 함께 사라진다."

**캐릭터 특성 (항상)**
- 샷건 공격력 +5%
- 샷건 발사당 총알 +1

**장착 효과**
- 가방 +2칸 (조끼 전용 칸)
- 보관함 한도 +2개 (5→7개)

**해제 효과 — 필사적인 도주**
- 이동속도 +10%
- 최대 체력 -60%

**플레이 스타일**

방어력을 희생하고 회피 능력을 극대화한다. 빠른 이동으로 적의 공격을 피할 수 있지만, 피격 시 생존 위험이 크게 증가한다.

---

## 3. 미니건 캐릭터 — 프로틴 쉐이크

**아이템 설명**

"무거운 미니건을 자유자재로 다루기 위해 매일 마시는 프로틴 쉐이크. 단백질 공급이 끊기면 근손실로 미니건을 들고 이동하기 어려워지지만, 느려진 만큼 신중하고 안정적인 사격에 집중한다."

**캐릭터 특성 (항상)**
- 미니건 정확도 +10%
- 이동속도 -10%

**장착 효과**
- 미니건 정확도 +10%

**해제 효과 — 근손실**
- 근손실로 이동속도 -20%

**특성 포함 최종 수치**
- 장착 시 : 미니건 정확도 +20%, 이동속도 -10%
- 해제 시 : 미니건 정확도 +10%, 이동속도 -30%

**플레이 스타일**

근손실로 무거운 미니건을 운반하는 속도가 느려지고, 장착 효과인 미니건 정확도 +10%도 잃는다.

### 구현 시 적용 규칙

- 캐릭터 특성은 고유 아이템 상태와 무관하게 항상 적용한다.
- 고유 아이템이 장착되어 있으면 장착 효과를 적용한다.
- 고유 아이템을 Inventory에서 제거하면 장착 효과를 제거하고 해제 효과를 적용한다.
- Storage 또는 Temporary에 있는 고유 아이템은 장착 상태로 인정하지 않는다.
- 고유 아이템을 다시 장착하면 해제 효과를 제거하고 장착 효과를 복원한다.
- 장착·해제를 반복하더라도 효과가 중복 적용되지 않도록 한다.
- 정확도는 같은 종류 %를 합산한 뒤 탄퍼짐 각도 × (1 − 정확도 합계)로 1회 적용한다. 헤비거너는 특성 +10%에 장착 효과 +10%를 더해 장착 시 +20%, 해제 시 특성 +10%만 남는다.
