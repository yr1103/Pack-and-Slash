## 플레이어용 아이템 설명 및 UI 개선안

### 1. 개선 목적

현재 아이템 설명에는 기본 공격 방식, 레벨별 특수 효과, 수치 정보가 혼합되어 있다. 플레이어가 아이템의 특징을 직관적으로 이해할 수 있도록 보상 카드와 Tooltip의 역할을 분리한다.

- **보상 카드:** 아이템 이미지, 이름, 종류만 표시한다.
- **Tooltip:** 아이템 설명, 레벨, 능력치, 특수 효과 및 진화 정보를 표시한다.
- **캐릭터 선택창:** 캐릭터 특징, 시작 무기 및 고유 아이템을 간결하게 안내한다.

기존 설명에 포함된 기술적인 수치는 Tooltip의 능력치 영역으로 분리하고, 설명 문장은 가능한 한 1~2문장으로 구성한다.

### 2. 일반 무기 설명 개선

| 아이템 | 플레이어용 설명 | Lv.3 특수 효과 |
|---|---|---|
| 권총 | 가장 가까운 적을 향해 탄환을 발사합니다. | **쌍권총:** 권총 2자루로 공격합니다. |
| 샷건 | 가까운 적에게 여러 발의 산탄을 퍼뜨립니다. | **넉백:** 산탄에 맞은 적을 밀어냅니다. |
| 미니건 | 빠르게 탄환을 연사하며, 탄창이 비면 재장전합니다. | **정밀 사격:** 탄환이 더 정확하게 발사됩니다. |

- 발사 간격, 공격력, 탄속, 사거리 등은 설명 문장에 포함하지 않고 별도 능력치 영역에 표시한다.
- Lv.3 특수 효과는 Lv.3부터 활성화되며 Lv.4~5에서도 유지된다.
- 레벨별 능력치는 실제 아이템 레벨 및 인접 효과를 반영한 계산 결과를 표시한다.

### 3. 패시브 아이템 설명 개선

| 아이템 | 플레이어용 설명 | Lv.3 전역 효과 |
|---|---|---|
| 개머리판 | 인접한 무기의 발사 간격을 줄입니다. | 경험치 획득량 증가 |
| 탄띠 | 인접한 무기의 공격력을 높입니다. | 이동속도 증가 |
| 냉각기 | 인접한 무기의 탄환 확산을 줄입니다. | 경험치 보석 획득 범위 증가 |

패시브 Tooltip에서는 효과를 다음과 같이 구분한다.

**인접 효과**
- Inventory에서 상하좌우로 맞닿은 무기에 적용한다.
- 일반 무기와 진화 무기 모두 적용 대상이다.
- 현재 아이템 레벨에 따른 효과 수치를 표시한다.

**Lv.3 전역 효과**
- Lv.3 이상부터 활성화된다.
- 인접 여부와 관계없이 Inventory에 장착되어 있으면 적용된다.
- Storage 및 Temporary에서는 적용되지 않는다.

기존 문서의 효과 수치와 실제 인게임 적용 수치가 다를 경우, 실제 코드 및 ScriptableObject를 확인하여 일치시키되 임의로 변경하지 않는다.

### 4. 진화 무기 설명 개선

| 아이템 | 플레이어용 설명 |
|---|---|
| 진화 권총 | 여러 자루의 권총으로 공격하며, 주기적으로 강력한 난사를 펼칩니다. |
| 진화 샷건 | 더 넓고 먼 범위에 산탄을 발사하며, 주기적으로 사방을 공격합니다. |
| 진화 미니건 | 더 많은 탄환을 발사하며, 하나의 탄환으로 여러 적을 관통합니다. |

진화 무기의 Tooltip에서는 일반 설명과 별도로 진화 조건을 표시한다.

**진화 조건**

| 진화 무기 | 필요 재료 |
|---|---|
| 진화 권총 | 권총 Lv.5 + 개머리판 Lv.5 |
| 진화 샷건 | 샷건 Lv.5 + 탄띠 Lv.5 |
| 진화 미니건 | 미니건 Lv.5 + 냉각기 Lv.5 |

공통 조건:
- 두 재료가 Inventory에서 상하좌우로 인접해야 한다.
- 특수 재화 4개가 필요하다.
- 진화 시 재료 아이템 2개가 소비된다.
- 각 무기 종류는 한 번만 진화할 수 있다.

진화 무기의 구체적인 전투 수치는 구현된 데이터에 따라 표시한다.

### 5. 캐릭터 고유 아이템 설명 개선

고유 아이템은 장착 상태에 따라 효과가 달라지므로 **아이템 설명 / 장착 효과 / 해제 효과**를 구분한다.

**카우보이 모자**

아이템 설명: 카우보이의 자존심이 담긴 모자. 벗으면 정확한 사격을 포기하고 빠르게 난사합니다.

- 장착 시: 기존 캐릭터의 권총 공격력 +10% 특성 유지. 해당 보너스가 모자 자체의 장착 효과인지 별도 캐릭터 특성인지는 기존 구현 확인 필요.
- 해제 시: 권총 공격속도 +60%, 탄환이 넓은 부채꼴 범위로 퍼짐.

**전투 조끼**

아이템 설명: 생존을 위한 두꺼운 조끼. 착용하면 수납공간이 늘어나고, 벗으면 더 빠르게 도망칠 수 있지만 생존력이 떨어집니다.

- 장착 시: Inventory 확장 2칸, Storage 보관 한도 +2개.
- 해제 시: 이동속도 증가, 최대 체력 감소.

**프로틴 셰이크**

아이템 설명: 무거운 미니건을 다루기 위한 필수 영양 보충제. 벗어나면 근손실로 이동이 느려지지만 더욱 신중하게 사격합니다.

- 장착 시: 기존 캐릭터 기본 특성 유지.
- 해제 시: 이동속도 감소, 정확도 증가.

고유 아이템의 해제 효과는 Inventory에서 제거된 경우에만 적용하며, Storage 및 Temporary에서는 장착 효과를 제공하지 않는다.

### 6. Tooltip 정보 표시 규칙

**일반 무기**
- 아이템 이름 / 레벨 / 종류
- 간단한 설명
- 현재 공격력 및 발사 간격 등 주요 능력치
- 인접 효과 적용 내역
- Lv.3 특수 효과

**패시브**
- 아이템 이름 / 레벨 / 종류
- 간단한 설명
- 현재 레벨의 인접 효과 수치
- Lv.3 전역 효과
- 대응하는 진화 무기

**진화 무기**
- 아이템 이름 / 종류
- 간단한 설명
- 주요 능력치
- 진화 무기 고유 효과

**캐릭터 고유 아이템**
- 아이템 이름 / 종류
- 간단한 설명
- 장착 효과
- 해제 효과

Lv.3 미만 아이템도 잠금 상태의 특수 효과를 미리 표시한다.

예시:
- Lv.1~2: `Lv.3 해금: 쌍권총`
- Lv.3~5: `Lv.3 활성: 쌍권총`

### 7. 캐릭터 선택창 설명 개선

| 캐릭터 | 특징 | 시작 무기 | 고유 아이템 |
|---|---|---|---|
| 카우보이 | 정확한 사격과 빠른 난사에 특화된 캐릭터 | 권총 | 카우보이 모자 |
| 겁쟁이 | 생존 장비를 활용하고 위급할 때 빠르게 도망치는 캐릭터 | 샷건 | 전투 조끼 |
| 헤비거너 | 강력한 연사력으로 적을 제압하는 캐릭터 | 미니건 | 프로틴 셰이크 |

캐릭터 선택창에는 특징과 함께 캐릭터 특성 수치 문구를 표시한다(구현 : "특성: 권총 공격력 +10%" 형식). 고유 아이템의 정확한 효과는 고유 아이템 Tooltip에서 확인할 수 있도록 한다.

### 8. 기존 수치와의 일치 여부 확인

현재 문서의 일부 수치가 이전에 결정한 밸런스 수치와 다르므로 UI 적용 전 확인이 필요하다.

| 항목 | 이전 확정 수치 | 현재 문서 수치 |
|---|---|---|
| 카우보이 해제 확산각 | 90° | 70° |
| 전투 조끼 해제 이동속도 | +35% | +10% |
| 전투 조끼 해제 최대 체력 | -35% | -60% |
| 전투 조끼 해제 받는 피해 | +20% | 미기재 |
| 프로틴 셰이크 해제 이동속도 | -10% | -20% |
| 프로틴 셰이크 해제 정확도 | +25% | 없음 (해제 효과는 이동속도 -20%만) |

또한 무기 및 패시브의 레벨별 성장 수치 역시 실제 구현 데이터와 확인해야 한다.

- UI 설명과 능력치 표시는 실제 게임에서 적용되는 값과 일치해야 한다.
- 확정되지 않은 수치는 임의로 표시하지 않는다.
- 에셋 임시값을 확정된 게임 규칙처럼 표시하지 않는다.
- Tooltip은 가능하면 기존 최종 스탯 계산 결과를 참조한다.
- 수치가 불일치하는 경우 Agent는 기존 코드와 문서의 차이를 보고하고 사용자 승인 후 수정한다.

### 9. UI 개선 작업 범위

이번 작업에서는 정보 전달 방식만 개선한다.

**구현 대상**
- 보상 카드 설명 간소화
- 일반 무기 및 패시브 Tooltip 문구 개선
- Lv.3 특수 효과 표시
- 고유 아이템 장착·해제 효과 구분
- 캐릭터 선택 화면의 특징 설명 개선

**제외 대상**
- 무기 및 패시브 밸런스 수치 변경
- 신규 아이템 효과 추가
- 진화 시스템 구현
- Inventory 구조 변경
- 전투 능력치 계산 방식 변경

기존 UI와 Tooltip 시스템을 재사용하고, 설명 개선을 위해 별도의 UI 관리 시스템을 추가하지 않는다.
