## 1. 목표와 시스템 경계

- 핵심 플레이: 레벨업·보스 상자에서 아이템 획득 → 메인 격자 배치 또는 Storage 보관 → 동일 종류·동일 레벨 합성 → 무기/패시브 인접 시너지 → 해당 조합 Lv.5 진화.
- 특수 재화는 **리롤(-2)**·**무기 진화(-4, 1차 테스트)**에 사용. 골드는 소모처가 없어 **레벨업 대체 보상에서 제외**.
- `Inventory`는 아이템 소유·위치·잠금·점유·유효성 판정을 소유하고, `LevelUpReward`는 후보 생성과 선택 상태, `Currency`는 재화 잔액·거래, `Monster/Boss`는 사망·드롭·상자 요청 이벤트를 담당한다.
- 현행 `InventoryData.cs`는 아이템 ID/이름/아이콘/타입/Shape/MaxLevel SO, `Inventory.cs`는 `ItemInstance`와 `InventoryCell`의 기본 틀이다. 이 파일들만으로 구현 완료를 가정하지 않는다.

## 2. 격자·Storage·완료 조건

| 항목 | 정책 |
|---|---|
| 외곽 배열 | **[확정] 10열×6행 = 60셀**  |
| 시작 활성 영역 | **[확정] 중앙 4×4 = 16셀**; 좌상단 원점 시 X=3~6, Y=1~4 |
| 확장 | **[확정] 현재 활성 영역과 상하좌우로 맞닿은 외곽 잠금 셀을 사용자가 선택**, 배열 범위 안에서만 확장 |
| 중간 보스 | **[확정] 05/10/15분 각 상자 수령 후 4셀 확장 선택** |
| 레벨업 확장권 | **[확정] 보상 화면 생성당 독립 5% 확률, 획득 시 1셀**. 각 보상 슬롯에 5%를 적용하지 않음 |
| Storage | **[확정] 기본 아이템 인스턴스 5개**, 면적과 무관. 조끼 착용 중 한도 **7개** |
| 조끼 2×2 | **[확정]** 메인 격자 4셀 점유; 장착 시 외곽 2셀을 **사용자가 선택**하고 조끼 제공 셀로 추적; Storage 한도 +2 |
| 조끼 탈착·판매 | **[확정] 허용**. 조끼 제공 2셀 잠금, Storage 한도 7→5. 기존 배치 오류와 초과 보관은 정리 상태로 남기고 `완료` 비활성화 |
| 전투 중 | 인벤토리 정리 없음. 보상·상자·정리 중 전투 시간/몬스터/투사체 정지 |

**완료 버튼 공통 검증**: 메인 장착 아이템은 모두 활성 셀 안에 있고 서로 겹치지 않음; 미배치 아이템 없음; 드래그 미처리 없음; Storage 수량 ≤ 현재 한도; 동일 계열 장착 무기 일반+진화 합계 ≤2; 선택 회차가 유효함. 조끼를 벗은 뒤 잠긴 칸에 아이템이 남거나 Storage가 `7/5`인 경우 사용자가 재배치·합성·판매하여 해결할 때까지 완료 금지. 정리 중에는 일시적으로 잘못된 상태를 허용한다.

**[미정]** 조끼 셀을 디딤돌로 확장한 영구 셀이 조끼 회수 후 고립되는 경우 연결을 강제할지; 조끼 다시 착용 시 과거 위치를 재활성화할지 재선택할지; 보스 +4칸을 모두 선택하기 전 완료 가능 여부. 확장 UI/셀 소유권 구현 시 별도 승인 필요.

## 3. 아이템 9종의 점유 도형과 캐릭터 고유 아이템

`#`는 점유 셀, `.`은 비점유. 표기의 `/`는 위에서 아래로 내려가는 행 경계. **90° 단위 회전** 지원. 좌우 거울 반전은 별도 도입하지 않는다.

| 분류 | 아이템 | 원형 Shape | 셀 수 | 비고 |
|---|---|---|---:|---|
| 일반 무기 | 권총 | `# / #` | 2 | 권총 계열 |
| 일반 무기 | 샷건 | `# / # / #` | 3 | 샷건 계열 |
| 일반 무기 | 미니건 | `..# / ###` | 4 | 미니건 계열 |
| 패시브 | 개머리판 | `## / .#` | 3 | 권총 진화 재료 |
| 패시브 | 탄띠 | `# / #` | 2 | 샷건 진화 재료 |
| 패시브 | 냉각기 | `#` | 1 | 미니건 진화 재료 |
| 진화 무기 | 진화 권총 | `##. / .## / ..#` | 5 | 엇갈린 모양 |
| 진화 무기 | 진화 샷건 | `### / .#. / .#.` | 5 | T자 모양 |
| 진화 무기 | 진화 미니건 | `#.# / ###` | 5 | U자 모양 |

**별도 캐릭터 고유 아이템**: 카우보이 모자 `##`(2셀, 가로), 전투 조끼 `## / ##`(4셀), 헤비거너 고유 아이템 `#`(1셀, 정식 명칭 미정). 이것들은 위의 무기·패시브·진화 무기 **9종과 별도**이며 일반 레벨 합성 대상이 아니다. 고유 아이템은 장착/탈착/판매할 수 있으며 캐릭터별 탈착 페널티는 관련 무기·캐릭터 명세를 따른다. **진화 무기 판매 불가**, Storage 보관 가능.

## 4. 아이템 레벨 및 합성 — 확정 정책

- 일반 무기·패시브 Lv.1~5. **동일 아이템 ID + 동일 레벨**의 인스턴스 두 개를 합쳐 `Lv.n + Lv.n → Lv.n+1` (n=1~4). Lv.5끼리 합성 불가.
- **메인↔메인, Storage↔Storage, 메인↔Storage 모두 허용**. 보상으로 새로 받은 미배치 아이템도 정상적으로 합성할 수 있다.
- **[추천, 기존 GDD와 합치]** 드래그 원본 인스턴스를 소비하고, 드롭 대상 인스턴스의 레벨만 +1. 대상의 기존 메인 위치·회전 또는 Storage 슬롯을 유지; 원본이 점유했던 셀/슬롯은 해제. 명시적 드롭 동작 없이 인접만으로 자동 합성하지 않는다.
- 동일 계열이라도 진화 무기와 일반 무기는 합성할 수 없다. 고유 아이템도 일반 합성 불가.
- 메인에 남으면 효과 재계산, Storage에 남으면 장착 효과 비활성. 합성 재료가 주무기였다면 유효한 남은 주무기 지정·승계 갱신 필요.
- 합성은 하나의 원자적 연산으로 처리하여 실패하면 아이템 소비·위치 갱신이 반쯤 남지 않도록 한다.
- **[추천]** 같은 계열 일반+진화 무기의 메인 장착 수는 **최대 2인스턴스**, Storage 보유량은 이 장착 한도에 포함하지 않는다. 물리적으로 여러 총구가 생겨도 인스턴스 1개로 센다.

## 5. 패시브 강화/전역 효과 및 중첩

**[확정]** 패시브가 특정 무기 계열과 짝을 이루는 것은 **진화 조건에만 사용**한다. 일반·진화 구분 없이 **상하좌우로 접촉한 모든 무기**에 무기 강화 효과 적용. 대각선은 미적용. 같은 패시브와 무기가 두 면 이상 접촉해도 **인스턴스 쌍당 1회**만 적용. 하나의 패시브가 여러 무기에 닿으면 무기별 1회, 여러 패시브가 한 무기에 닿으면 개별 효과 합산.

| 패시브 | 무기 인접 효과 Lv.1→5 (**1차 채택**) | Lv.3부터 전역 효과 (**확정한 초기값**) |
|---|---|---|
| 개머리판 | 발사 간격 감소 **4 / 7 / 10 / 13 / 16%** | 경험치 획득량 **+10%** |
| 탄띠 | 공격력 증가 **6 / 9 / 12 / 15 / 18%** | 이동속도 **+10%** |
| 냉각기 | 랜덤 탄퍼짐 감소 **10 / 15 / 20 / 25 / 30%** | 경험치 젬 수집 반경 **+15%** |

- **[확정]** Lv.3에서 전역 효과가 켜지고 Lv.4·5에서 **전역 효과 수치는 추가 증가 없음**. 인접 여부와 관계없이 **메인에 장착**돼 있으면 발동, Storage는 비활성.
- **[확정]** 패시브 인스턴스별로 동일 종류 효과 **단순 합산**, 필요한 능력치에만 제한 상한을 둔다. 진화 무기도 예외 없이 인접 효과를 받는다.
- **[테스트]** 발사 간격 감소 합계 상한 50%, 랜덤 탄퍼짐 감소 합계 상한 70% (최소 0). 이동속도 보너스 총합 상한 +50%는 레벨업 강화와 탄띠 전역 버프 등을 함께 계산. 무기 공격력은 우선 제한 없음. XP/수집 반경 전역 보너스 상한은 현재 별도 확정되지 않음.
- [추천] `최종 발사 간격 = 기본 간격 × (1 − clamp(감소율 합계,0,0.5))`로 명시하며 발사 **간격 감소**와 **발사속도 증가**를 혼용하지 않는다. 탄퍼짐이 원래 0인 무기는 냉각기 인접 효과가 0일 수 있음. 샷건은 고정 펠릿 패턴과 랜덤 편차를 구분하여 후자만 줄이는 안을 추천한다.
- [추천] SO의 원본 스탯 수정 금지. Inventory의 장착 결과가 바뀌면 기초값 + 런 강화 + 장착 효과를 다시 계산하여 Runtime Weapon/Player 스탯 갱신.

## 6. 진화 조건·소비·미배치 결과

| 진화 | 요구 재료 | 결과 도형 |
|---|---|---|
| 진화 권총 | 권총 Lv.5 + 개머리판 Lv.5 | `##. / .## / ..#` |
| 진화 샷건 | 샷건 Lv.5 + 탄띠 Lv.5 | `### / .#. / .#.` |
| 진화 미니건 | 미니건 Lv.5 + 냉각기 Lv.5 | `#.# / ###` |

1. **[확정]** 두 재료는 메인 인벤토리에서 정상 장착되고 상하좌우 인접, 필요한 재화 보유, 해당 계열 진화 미완료일 때만 `진화` 활성. 진화 비용 **4개 [테스트]**.
2. 버튼 클릭 → 확인 팝업: `무기 진화하시겠습니까?` / `주의: 다음 보상부터 [일반 무기]와 [대응 패시브]가 등장하지 않습니다.` / `진화 무기는 판매할 수 없습니다.` / 소모 재화와 재료 명시.
3. 확인 시 조건 재검증 → 두 인스턴스 제거 및 점유 해제 + 특수 재화 차감 + **종류별 진화 이력 1회 기록** + **진화 아이템 5칸 1개를 미배치 상태로 생성**. 취소 시 아무 변경 없음; 확인 처리는 중복 실행 불가.
4. 새 아이템은 **플레이어가 직접** 메인에 배치·회전하거나 Storage에 보관. 다른 아이템 재배치·일반 아이템 판매·합성으로 공간 마련 가능. **오류 또는 미배치 남으면 `완료` 금지**.
5. 진화 이후에도 동일 계열 일반/진화 무기 메인 장착 합계 최대 2. 진화 무기 판매 불가, 재진화 불가, 일반 무기와 합성 불가.
6. 진화에 소비된 패시브의 전역 효과·인접 효과는 사라지며, 남은 다른 패시브 인스턴스의 효과는 유지. 진화 무기는 모든 종류 패시브의 인접 효과를 받을 수 있음.
7. 진화 이후 이미 소유한 일반 무기/패시브 복제본은 유지·판매·Storage 이동·기존 보유 재료끼리 합성 가능. 이후 **새 보상 출현만 영구 금지**.

**[미정·주의]** 진화 무기는 판매·환불이 불가능하므로, 메인에도 Storage에도 배치할 수 없고 일반 아이템을 정리할 여지도 없는 상태를 막을 안전장치(사전 검증, 별도 임시 대기 복구 등) 필요. 사용자가 확정한 **확인 즉시 진화·미배치 결과 생성**을 자의로 '진화 전 자동 배치 강제'로 바꾸면 안 된다.

## 7. 레벨업 후보 생성과 최대 레벨 필터

### 7.1 후보 제외 순서

1. **진화 영구 제외**: 이번 판에 특정 계열이 진화했다면 그 **일반 무기 + 대응 패시브** 두 종류를 모든 *새로운* 보상 목록에서 제거한다.
2. **Lv.5 보유 중 임시 제외**: 메인 또는 Storage에 해당 아이템 종류의 Lv.5 인스턴스가 **하나라도** 있다면 해당 종류를 신규 후보에서 제거한다. 판매 등으로 **모든 Lv.5가 사라지면 재등장 가능**, 단 1번 영구 제외가 항상 우선.
3. 현재 보상 타입별 추가 제한·획득 가능 여부를 판정한 뒤 중복 없는 후보를 뽑는다.
4. **[추천]** 이미 획득했지만 미배치 상태인 Lv.5도 보유 중으로 계산하여 상태 악용을 방지한다. 이 포함 여부 자체는 메인/Storage만 명시적으로 확정됐던 범위를 확장하는 제안이다.
5. 동일 화면의 후보를 생성한 후에는 선택 도중 자동 재생성하지 않는다. 이후 회차에서는 새 소유 상태로 재평가한다.

### 7.2 레벨업 제시·선택

- **[확정]** 레벨업 정리 화면에서 **서로 다른 후보 3개**를 보여주고, **처음 표시한 그 3개 중 최대 2개** 선택한다. 첫 선택 후 후보 자동 재추첨하지 않는다.
- **[확정]** 보상 **선택 전**에만 특수 재화 **2개**를 지불하고 리롤 가능; 하나라도 선택한 뒤에는 리롤 불가. 리롤은 현재 3개 후보를 다시 추첨하는 것을 기본 구현안으로 제시한다.
- 일반 아이템 종류 후보가 3개 미만이면 **부족한 칸만** 아래 대체 보상으로 채운다. 충분할 때는 기본 능력치 보상이 일반 아이템 후보를 밀어내지 않는다. **한 화면 안 동일 종류 중복 표시 금지 [추천]**, 다음 레벨업에서 동일 종류 재등장 허용.
- 무기·패시브 획득은 새 아이템 인스턴스를 미배치로 생성, 직접 메인/Storage 배치·합성·판매 후 완료. 즉시형/런 강화 보상은 선택 확정 시 적용하고 메인/Storage를 점유하지 않는다.
- [기존 GDD] 여러 레벨업 누적 시 게임은 계속 일시정지하고 각 회차를 순차적으로 완료. 보스 상자 접촉 시에도 대기 레벨업을 먼저 모두 처리한다.

### 7.3 대체 보상 5종 (골드 제외)

| 보상 | 지급량 / 효과 | 누적·상한 | 상태 |
|---|---|---|---|
| 특수 재화 | **+2개** | 반복 획득 | **[테스트]** |
| 체력 회복 | 현재 최대 HP의 **20% 즉시 회복** | 최대 HP 초과 금지. 체력 가득 차 있으면 후보 제외 [추천] | **[테스트]** |
| 생명력 흡수 | **+0.5%p** 런 강화 | **[확정] 누적 피흡률 상한 5%; 1초 회복량 상한 최대 HP의 5%** | 지급량 [테스트] |
| 이동속도 | 기본 이동속도 기준 **+2%** 런 강화 | **[확정] 전체 이동속도 보너스 +50%** | 지급량 [테스트] |
| 최대 체력 | 기본 최대 HP 기준 **+5%** 런 강화 | 별도 상한 미확정; 증가한 최대 HP만큼 현재 HP도 +증가분 [추천] | **[테스트]** |

- **[추천]** 피흡은 실제 적용된 적 피해량(오버킬 제외)의 비율로 계산하고 초당 최대 HP 5% 회복으로 제한. HP는 소수 회복량을 누적해 소량 연타 시 반올림 손실 방지.
- [추천] 상한에 도달한 런 강화 후보는 제외. 체력 회복을 선택하더라도 상자/전투 중 실제 적용 시점에서 HP를 넘지 않도록 재검증.
- [미정] 대체 보상이 필터 후 3종 이하가 되는 극단 상태(HP 만피, 피흡/이속 상한 등)에서는 특수 재화 등 **동일 종류 보상 중복 허용** 또는 보상 개수 축소 등 최종 폴백이 필요. 일단 골드를 다시 도입하지 않는다.

### 7.4 인벤토리 1칸 확장권 5% 처리

- **[확정]** 일반 보상 생성 단계의 **독립 5% 확률**, 대체 보상 5종에는 포함되지 않음. 화면 한 번당 5%이며, 각 슬롯당 5%가 아님. 선택해 획득하면 +1칸을 사용자가 외곽에서 선택. 60칸 모두 열렸다면 후보에서 제외.
- **[추천]** 성공 시 일반 아이템 후보 슬롯 1개를 확장권으로 대체하는 방식을 우선 검토한다. 정확히 어느 슬롯을 대체하는지, 후보 부족 시 슬롯 계산 및 **리롤 시 5%를 다시 판정할지/최초 판정을 유지할지**는 별도로 결정해야 한다. 본 초안에서 임의 확정하지 않는다.

### 7.5 레벨업 보상 선택 종료 예외

- [추천] 0개 선택 후 스킵은 명시적인 '건너뛰기'만 허용하여 실수 방지. 1~2개 선택 후 확정.
- [미정] 판매가 ‘이미 획득한 아이템 판매’인지 ‘선택하지 않은 보상 슬롯 직접 판매’인지, 미선택 슬롯 리롤을 어떻게 처리할지. 기존 GDD에는 선택/판매된 슬롯을 유지하고 나머지만 리롤하는 문구가 있으므로 **최신 '선택 전만 리롤' 정책으로 UI 문구 동기화 필요**.

## 9. MonsterSystem.md 수정사항 — 독립 반영 절

이 절은 기존 `MonsterSystem.md`의 **수정 지시안**이며, 파일 자체를 직접 덮어쓰는 변경이 아니다.

### 9.1 엘리트 스폰 (§4, §7 Q01/Q02, M11)

**[확정]** 엘리트는 전투 게임 시간 **03:00 / 08:00 / 13:00** 각각 **1마리**만 등장. 각 이벤트 발생 순간 플레이어 좌표를 사용하여 맵의 **네 경계 선분 중 플레이어와 거리가 가장 가까운 경계 면**을 고르고, **해당 경계의 중점**에서 등장한다. 18분 이벤트와 추가 반복 이벤트 없음. '네 경계에서 4마리 동시 등장' 및 '가장 가까운 면 선택 폐기'라는 기존 §4 문구는 **삭제/교체**. 가까운 경계의 **중점**은 플레이어 자체에서 가장 가까운 경계점과 다를 수 있다.

- 맵 경계 좌표 기준은 실제 100×100 절차적 맵의 유효 타일/World Bounds를 확인한다. 동거리일 때 방향 우선순위는 **[미정]**.
- 기존 Flow Field가 정의되지 않은 **맵 바깥 위치에서 직접 그리드 좌표를 조회하지 않는다**. 외부 진입 연출과 유효 셀 이동 접속은 M11 착수 전 검증·승인 필요.
- 몬스터 활성 최대 500 및 보스 출현과의 충돌 방지 정책은 기존 미정으로 보존한다.

### 9.2 엘리트 사망·드롭 (§2 드롭 규칙, M11)

**[확정] 사망이 단 한 번 확정되는 순간** 다음 두 처리를 수행한다.

1. **경험치 젬 1개 월드에 드롭**: 기존 강화 젬/색상 후보 및 기본 몬스터 XP **10배** 정책을 유지. 젬 수집이 이루어져야 XP 지급.
2. **특수 재화 1개 즉시 지급**: 월드 재화 아이템을 드롭하지 않고, 플레이어가 별도로 주울 필요 없이 공용 재화 잔액에 즉시 추가. **XP 젬 획득 여부와 독립**.

사망 이벤트 중복 방지 및 풀 초기화 시 지급 상태 초기화. **재화 지급 실패로 XP 젬이 중복 드롭되거나, XP 젬을 줍지 않았다는 이유로 재화 지급이 지연되지 않도록** 독립 검증한다.

### 9.3 보스 상자와 재화 (§5.6, M09)

- 05/10/15분 중간 보스 사망 시 `Silver_Chest` **1개 드롭**, 경험치 젬 없음. 보스가 사망하는 순간 특수 재화 **즉시 지급하지 않음**.
- 플레이어가 상자를 획득하면 상자 보상 요청을 1회 등록하고 **대기 중인 레벨업을 모두 먼저** 완료한다. 그 다음 상자 보상 처리 단계에서 **특수 재화 +3개 확정 지급**, **인벤토리 4칸 확장 선택**, **상자 후보 5개 중 최대 3개 선택**을 수행한다.
- 보스 상자 +3개는 후보 5개 중 하나가 아니라 **별도의 확정 보상**. 상자 1개당 한 번만 지급.
- 20분 최종 보스는 처치 즉시 클리어 / 23분까지 생존 클리어. 추가 상자·재화 지급 없음.

## 10. 구현 API 및 작업 경계 (권장, 명칭 가안)

| 기능 | 소유 시스템 | 요청 / 이벤트의 의미 |
|---|---|---|
| 확장 가능한 외곽 셀 조회/확정 | Inventory | 활성·외곽·조끼 소유권 일관성 검사; 실제 구현 사용자 소유 |

| 인접 관계 스냅샷 | Inventory | 장착 무기·패시브 인스턴스 쌍 제공, 동일 쌍 접촉 중복 제거 |
| 장착/소유 상태 변경 | Inventory | 효과 계산·보상 후보 재생성에 필요한 변경 알림 |
| 보상 후보 생성 | LevelUpReward | 진화 이력, 소유 Lv.5, 확장권 확률 및 fallback 반영 |

| 엘리트 사망 확정 | MonsterSystem | XP 젬 드롭 요청 + Currency +1 이벤트; 몬스터의 직접 잔액 필드 변경 금지 |
| 보스 상자 획득 | Boss/Chest/GameFlow | 보상 1회 큐 등록→대기 레벨업 처리→상자 확정 보상 지급 |
| 진화 확정 | EvolutionService | 재료/재화 동시 검증·소비, 진화 이력 및 미배치 결과 생성 |
| 전투 최종 스탯 | Combat/Player Stat | Inventory 결과를 읽어 스탯 재산출, SO 원본 불변 |

작업 순서 제안: **(1) Inventory 격자 4×4/10×6 및 Storage/조끼 소유권 → (2) 합성/패시브 재계산 → (3) 레벨업 보상 필터와 3중2택·확장권 → (4) Currency/판매/리롤/진화 → (5) MonsterSystem 엘리트 즉시 지급·상자 지급 통합 → (6) 전체 회귀 테스트**. 각 변경 전에 대상 파일/API·영향 범위를 브리핑하고 승인 후 진행한다.

## 11. 남은 정책 미정 사항과 회귀 테스트

### 11.1 아직 확정하지 않은 정책

1. **확장권 리롤 정책:** 최초 5% 판정 유지 / 리롤 시 재판정 중 선택. 슬롯 대체 방식까지 확정 필요.
2. **후보 부족 최후 폴백:** 대체 보상 5종 중 적용 가능한 종류가 3개 미만인 경우 슬롯 중복을 허용할지, 표시 개수를 줄일지.
3. **보스 상자 후보 부족:** 5중3택에도 Lv.5·진화 제외 필터를 적용할지, 대체 보상을 허용할지. 원 GDD에는 **Lv.2 장비 확정** 언급이 있어 해당 규칙과 충돌 검증 필요.
4. **진화 후 절대 배치 불가:** 새 진화 무기 판매 불가+Storage 포화 시 정리 화면 교착 방지책.
5. **조끼 제공 셀 회수 시 고립된 영구 셀** 및 재장착 때 2칸 재선택 여부.
6. **보상 후보 직접 판매**와 리롤 상호 작용: 기존 GDD의 '미처리 슬롯만 리롤' 문장을 최신 '선택 전만 리롤'에 맞춰 확정 수정.
7. **재화/스탯 수치 미확정:** 판매, 진화 4, 대체 +2 등은 1차 테스트값이며 최종 밸런스 확정 아님. 일반 아이템 Lv.2 보상 실제 확률과 고유 아이템 재획득 방식도 미정.
8. **엘리트 경계 동률/그리드 외 진입**과 몬스터 500 활성 상한에서 예약 보스·엘리트 등장 보장.

### 11.2 회귀 테스트 체크리스트

- [ ] 초기 4×4는 10×6 정중앙(X=3~6, Y=1~4)에서 활성, 모든 외곽 확장 4방향 동작.
- [ ] 조끼 2셀 선택 후 소유권 유지, 탈착 시 잠금/Storage 7→5, 오류 있는 동안 정리 완료 불가.
- [ ] 9개 일반·진화 도형 회전/점유와 중복 셀 참조 검증.
- [ ] 메인·Storage 교차 합성에서 원본 1개만 소모, 대상 위치·회전 유지.
- [ ] Lv.3 패시브 전역 효과는 비인접에서도 적용, 진화 무기는 모든 패시브 인접 강화 가능.
- [ ] 동일 무기/패시브 두 면 접촉 시 1회만 시너지, 서로 다른 패시브 중첩 단순 합산.
- [ ] Lv.5 메인·Storage 보유 중 제외, 최후 Lv.5 판매 시 재등장, 진화 후 영구 제외 우선.
- [ ] 리롤 비용 -2, 선택 후 불가, 처음 제시한 3개 중 최대 2개만 수령.
- [ ] 확장권 보상 화면당 5%, 1칸 선택, 대체 보상 풀과 분리.
- [ ] 엘리트 3/8/13분 각각 가장 가까운 경계 중점에 1마리, 이벤트 중복 없음.
- [ ] 엘리트 사망 즉시 재화 +1 **딱 한 번**; XP 젬 1개는 월드 잔존, 수집 시 XP 지급.
- [ ] 중간 보스 5/10/15분 상자 접촉 1회당 재화 +3; 보스 사망 순간에는 재화 증가 없음.
- [ ] 상자 접촉 시 대기 레벨업 선처리, 이후 4셀 확장과 5중3택 보상.
- [ ] 20분 최종 보스 처치 또는 23분 생존 클리어, 별도 경제 드롭 없음.
- [ ] 재화 거래 합산과 로그 일치(엘리트+상자+판매+대체−리롤−진화).

**초안의 핵심 결론**: 엘리트 재화는 **사망 확정 시 즉시 지급**, 경험치 젬은 **별도 월드 드롭 및 수집 후 XP 획득**; 중간 보스 재화는 **상자 획득 후 지급**으로 책임과 시점을 분리한다. Inventory의 4×4→10×6, 조끼 확장, 인접 효과, 합성, 진화, 레벨업 보상, 특수 재화 경제는 위 규칙을 기준으로 연결하며, `[미정]` 항목은 Agent가 임의 확정하지 않는다.
