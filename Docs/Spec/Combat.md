## 계약

### 경험치 보석
- 일반 몬스터 처치 시 월드에 경험치 보석을 생성한다.
- 플레이어의 수집 감지 Collider는 **초기 크기가 플레이어 몸과 동일**하다.
- 보석이 Collider에 닿으면 **플레이어의 정확한 중심(Pivot)으로 이동**하고, **중심 도착 시** 보석을 제거/반환하면서 경험치를 증가시키고 획득 효과음을 재생한다.
- 사망 직후나 Collider 접촉 순간에 경험치를 미리 지급하지 않는다. 한 보석의 경험치는 **정확히 1회** 지급한다.
- **냉각기 Lv.3**의 획득 반경 증가는 감지 Collider 범위에 반영한다. 반경이 변해도 이미 이동 중인 보석의 지급을 누락하거나 중복하지 않는다.
- 대량 드롭 대비 풀링·병합·수명 정책은 성능 측정 후 결정한다.

### 장비 효과
- 장착·합성·판매·Storage 이동 후 **장착 무기·시너지의 유효 상태를 다시 계산**할 수 있어야 한다.
- 각 무기 인스턴스는 독립적으로 공격하며 **Lv.3 고유 효과도 인스턴스별로 중복 적용**한다. (예: 권총 Lv.3 두 개면 각각 2자루 공격)
- 중복 무기 디버프는 현재 미적용이며 밸런스 이후 선택한다.
- **무기 3종:** 권총 / 샷건 / 머신건, Lv.1~5. Lv.3 고유 효과는 각각 권총 2자루, 넉백, 탄퍼짐 감소
- **패시브 3종:** 개머리판(권총: 공격속도 증가, Lv.3 경험치 획득량 증가) / 냉각기(머신건: 탄퍼짐 감소, Lv.3 경험치 보석 획득 반경 증가) / 탄띠(샷건: 공격력 증가, Lv.3 이동속도 +10%)
- 패시브 Lv.3 효과가 캐릭터 전역에 영향을 주는 경우, 인접·중복에 따른 중첩 정책을 확정한 뒤 구현한다. 미정 수치를 임의로 상수화하지 않는다.

### 캐릭터
- 카우보이(권총 공격력 +10%, 모자 1×2), 겁쟁이 생존자(샷건, 조끼 2×2, **가방 추가 +2칸**), 헤비거너(머신건, 1×1 필수품 미정, 이동속도 -10%, 정확도 +10%)

### 진화
- **조건:** 장착 무기 Lv.5 + 대응 패시브 Lv.5 + 서로 인접 + 특수 재화 지불
- **권총 + 개머리판:** 권총 4자루 및 주기적 난사
- **머신건 + 냉각기:** 발사 탄환 수 증가, 관통(최대 5마리 검토)
- **샷건 + 탄띠:** 발사 반경 증가, 주기적인 360도 방사형 사격
- 진화 후 가방 공간은 1~2칸 추가하는 방향을 검토한다. 최종 점유 셀과 공간 부족 처리 방식은 결정 전 임의로 적용하지 않는다.
- 진화 시 패시브 소모/유지, 결과 무기의 중복 장착 한도와 가격은 기능 브리핑에서 확정한다.
- 인벤토리 확장·배치 검사와 인접 판정은 `Inventory.md`(개발자 담당)를 사용한다.

## 테스트 기준

- **전투:** 보석 접촉 → 중심 이동 → 도착 시 1회 지급·효과음, 획득 반경 증감, 중복 무기 독립 공격 및 Lv.3 효과 중복, 패시브 시너지 재계산

## 미정 파라미터

- 중복 무기 밸런스
- 캐릭터 3 필수 아이템 최종 디자인, 필수 아이템 판매/착용 해제 정책
