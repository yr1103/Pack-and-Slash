## 계약

### 경험치 보석
- 일반 몬스터 처치 시 월드에 경험치 보석을 생성한다.
- 플레이어의 수집 감지 Collider는 **초기 크기가 플레이어 몸과 동일**하다.
- 보석이 Collider에 닿으면 **플레이어의 정확한 중심(Pivot)으로 이동**하고, **중심 도착 시** 보석을 제거/반환하면서 경험치를 증가시키고 획득 효과음을 재생한다.
- 사망 직후나 Collider 접촉 순간에 경험치를 미리 지급하지 않는다. 한 보석의 경험치는 **정확히 1회** 지급한다.
- **냉각기 Lv.3**의 획득 반경 증가는 감지 Collider 범위에 반영한다. 반경이 변해도 이미 이동 중인 보석의 지급을 누락하거나 중복하지 않는다.
- 대량 드롭 대비 풀링·병합·수명 정책은 성능 측정 후 결정한다.

### 장비 효과
- 장착·합성·판매·Storage 이동 후 **장착 무기·시너지의 유효 상태를 다시 계산**할 수 있어야 한다.
- 각 무기 인스턴스는 독립적으로 공격하며 **Lv.3 고유 효과도 인스턴스별로 중복 적용**한다. (예: 권총 Lv.3 두 개면 각각 2자루 공격)
- 중복 무기 디버프는 현재 미적용이며 밸런스 이후 선택한다.
- **무기 3종:** 권총 / 샷건 / 미니건, Lv.1~5. Lv.3 고유 효과는 각각 권총 2자루, 넉백, 탄퍼짐 감소
- **패시브 3종:** 개머리판(권총: 공격속도 증가, Lv.3 경험치 획득량 증가) / 냉각기(미니건: 탄퍼짐 감소, Lv.3 경험치 보석 획득 반경 증가) / 탄띠(샷건: 공격력 증가, Lv.3 이동속도 +10%)

### 조준·발사
- 모든 무기는 **플레이어 중심 XZ 평면 360°** 범위에서 무기 인스턴스별 감지 거리 안의 최근접 적을 **독립적으로** 선택한다.
- 탄은 발사 순간 표적 위치를 향해 직진하며 **유도하지 않는다.**
- 회전은 짧은 시각 연출이다. 발사 조건이 준비되면 회전 완료를 기다리지 않고 발사하며, 회전에 따른 지연·정확도 페널티는 없다. 적이 없으면 탐색 회전을 하지 않는다.
- 권총·미니건 탄은 **Game View 화면 밖에서 피해·넉백·관통 등 전투 효과를 발생시키지 않는다.**

| 무기 | 감지 거리 | 발사 | 탄속 | 사거리 |
|---|---|---|---|---|
| 권총 | 김 | **1.5초**마다, 재장전 없음 | 보통 | 김 |
| 샷건 | 짧음 | **2.5초**마다 부채꼴 균등 간격 산탄, 재장전 없음 | 빠름 | 짧음 |
| 미니건 | 권총보다 약간 김 | 좁은 부채꼴 무작위 탄퍼짐 연사, **탄창 100발 / 재장전 5초** | 느림 | 김 |

- 위 수치는 초기값이며 인스펙터에서 조절한다. 감지 거리·탄속·펠릿 수·퍼짐각·연사 속도는 실험 후 결정한다.
- 샷건 다중 펠릿 넉백은 상한 또는 점감을 두고, 보스에는 저항 배율을 적용한다. 넉백은 몬스터 이동 시스템에 요청만 전달한다.

### 주무기와 총기 배치
- 장착 무기 중 **주무기 하나**만 캐릭터 몸통 회전을 제어하고 손에 든다. 나머지 총기는 부유 무기로 독립 조준한다.
- 주무기는 인벤토리 UI에서 수동 지정할 수 있다. 지정이 없으면 시작 무기가 주무기다. **시작 무기도 판매할 수 있다.**
- 주무기가 판매·해제되면 **진화 → 고유 무기 → 최고 레벨 → 인스턴스 ID(먼저 획득)** 순서로 자동 승계한다. 장착 무기가 없으면 자동사격을 멈춘다.
- 총기 수 `N`만큼 주무기 손 총기를 0°로 하여 플레이어 주변에 `360°/N` 간격으로 배치한다.
- 패시브 Lv.3 효과가 캐릭터 전역에 영향을 주는 경우, 인접·중복에 따른 중첩 정책을 확정한 뒤 구현한다. 미정 수치를 임의로 상수화하지 않는다.

### 캐릭터
- 카우보이(권총 공격력 +10%, 모자 1×2), 겁쟁이 생존자(샷건, 조끼 2×2, **가방 추가 +2칸**), 헤비거너(미니건, 1×1 필수품 미정, 이동속도 -10%, 정확도 +10%)
- 헤비거너 정확도 +10%는 미니건 탄퍼짐 각도 0.9배로 적용하는 것을 제안한다. (`WeaponSystem.md` 설계 제안)
- **고유 아이템 탈착:** 캐릭터 고유 아이템은 탈착·판매할 수 있다. Storage 보관도 탈착이다. 탈착 상태에서는 작은 버프와 **그보다 큰 디버프**를 받고, 재장착하면 원래 효과로 완전히 복구한다. 판매하면 재획득 전까지 탈착 상태가 유지된다.
- 탈착 상태는 인벤토리 `완료` 시 장착 격자 유효 배치 여부로 갱신하며, 디버프를 중복 적용하지 않는다. 시작 무기 판매만으로는 탈착 페널티가 생기지 않는다.

| 캐릭터 / 고유 아이템 | 탈착 디버프 (초기 제안) | 탈착 버프 (초기 제안) |
|---|---|---|
| 카우보이 / 모자 | 권총 랜덤 탄퍼짐 ±15° | 권총 발사 간격 10% 감소 |
| 겁쟁이 생존자 / 전투 조끼 | 받는 피해 +30%, 가방 +2칸 비활성화 | 이동속도 +5% |
| 헤비거너 / 고유 1×1 | 미니건 탄퍼짐 +40%, 재장전 +20% | 이동속도 +5% |

- 수치는 플레이 테스트 후 조절한다. 전투 조끼 +2칸 회수 시 해당 칸에 아이템이 있으면 탈착·판매를 확정하지 않고 재배치를 안내한다. (회수 칸 판정은 `Inventory.md` 계약 사용)

### 진화
- **조건:** 장착 무기 Lv.5 + 대응 패시브 Lv.5 + 서로 인접 + 특수 재화 지불
- **권총 + 개머리판:** 권총 4자루 및 난사 (쿨다운 **10초** / 지속 **3초**)
- **미니건 + 냉각기:** 발사 탄환 수 증가, 탄환당 서로 다른 적 최대 **3마리** 관통 (초기값, 같은 적은 1회만 집계)
- **샷건 + 탄띠:** 발사 반경 증가, **4초**마다 360도 방사형 사격
- 진화 수치는 모두 인스펙터에서 조절하며, 각 무기 인스턴스의 스킬 타이머는 독립이다.
- 진화 후 가방 공간은 1~2칸 추가하는 방향을 검토한다. 최종 점유 셀과 공간 부족 처리 방식은 결정 전 임의로 적용하지 않는다.
- 진화 시 패시브 소모/유지, 결과 무기의 중복 장착 한도와 가격은 기능 브리핑에서 확정한다.
- 인벤토리 확장·배치 검사와 인접 판정은 `Inventory.md`(개발자 담당)를 사용한다.

## 테스트 기준

- **전투:** 보석 접촉 → 중심 이동 → 도착 시 1회 지급·효과음, 획득 반경 증감, 중복 무기 독립 공격 및 Lv.3 효과 중복, 패시브 시너지 재계산
- **무기:** 360° 최근접 탐지, 비유도 탄, 화면 밖 피해 0건, 무기별 발사 주기·탄창·재장전, 주무기 승계, 고유 아이템 탈착·재장착 복구 (상세 체크리스트는 `WeaponSystem.md` §12)
