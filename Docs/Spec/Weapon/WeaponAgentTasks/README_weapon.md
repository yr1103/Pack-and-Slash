# Weapon System — AI Agent 단계별 업무지시서

> 문서 유형: **단일 작업 지시서**. 각 단계는 독립적인 승인·구현·검증 단위다.
> 원문: `WeaponSystem.md` / `GDD.md` / `GameFlow.md` / `Roadmap.md`
> 주의: 이 문서는 원문을 대체하는 새 기획서가 아니라 **원문을 작업 단위로 분리한 실행 가이드**다.

## 실행 원칙

**한 번의 Agent 요청에는 반드시 작업 ID 하나만 포함한다.** 해당 작업에서 요구하지 않은 다른 무기, 다른 레벨, 진화, UI, Inventory 내부 알고리즘까지 선행 구현하지 않는다. 다음 ID는 사용자 검토·승인 후 착수한다. 기존 코드가 이미 충족한다면 중복 구현하지 말고 증거와 빠진 테스트만 보고한다.

각 업무의 `선행 작업`은 **작업 ID를 완료했다는 사실보다 인터페이스·동작 테스트를 통과했다는 뜻**이다. 인벤토리/몬스터 알고리즘은 개발자 직접 구현 영역이므로 계약 인터페이스와 테스트용 스텁만 합의한다.

## 공통 작업 규칙
- **기준 문서:** `WeaponSystem.md` (최우선 무기 상세), `GDD.md`, `GameFlow.md`, `Roadmap.md`. 충돌·미정 발견 시 임의 확정하지 않고 사용자에게 보고한다.
- **권한:** AI Agent는 요청된 단계 범위에서만 개발한다. **개발자 직접 구현 영역인 인벤토리 격자·회전·배치·합성·인접 판정, Flow Field/Vector Field, Spatial Hash/Separation의 내부 구현을 수정하지 않는다.** 해당 기능과 연결할 때는 계약안/Mock/Adapter를 제시하고 승인받는다.
- **승인 절차:** 착수 전에 현재 코드/Scene/Prefab 검사 → 변경 파일·설계·미정 사항·영향 범위 브리핑 → 승인 후 구현 → 컴파일/동작 검증 → 결과·미검증·스크린샷/로그 보고 → 다음 작업은 별도 승인. Git 커밋/PR/병합, Packages/ProjectSettings 변경도 사전 승인 없이 하지 않는다.
- **유지해야 할 계약:** 3D 탑다운 XZ, `CharacterController.SimpleMove`; 모든 무기 플레이어 중심 360° 탐지; 무기 인스턴스별 최근접 적 독립 탐색; 회전은 짧은 시각 연출이고 발사 대기·정확도 페널티가 없다. 발사 탄은 비유도. 1개 주무기만 몸통 회전을 제어하고 나머지 총기는 독립 조준한다.
- **구현 규칙:** `[SerializeField] private`로 튜닝, 읽기 전용 프로퍼티/이벤트로 상태 노출. ScriptableObject는 설정, 인스턴스는 런타임 상태. 풀에서 재사용한 투사체는 상태 완전 초기화. 실제 코드 구조는 현재 프로젝트를 조사하여 최소 변경한다.
- **완료 보고 형식:** 변경 파일 및 이유 / 연동 API·이벤트·Inspector 연결법 / 수행한 테스트와 결과 / 수행하지 못한 테스트·오류 / 미결정 사항 / 다음 작업 전 사용자 승인 필요 사항.

## 권장 진행 흐름

1. `W00` 조사·계약 확정 → `W01` 데이터 분리 → `W02` 표적 탐색 → `W03` 투사체 기반.
2. 기본 공격은 `W04` 권총 → `W05` 샷건 → `W06` 미니건으로 각각 독립 검증.
3. `W07` 부유 무기·원형 배치 → `W08` Lv.3 → `W09` 패시브 스탯 합성 → `W10` 진화.
4. `W11` 주무기 승계 → `W12` 고유 아이템 탈착 → `W13` 일시정지 및 통합 회귀 테스트.

일부 작업은 병렬 가능하지만 **공유 무기/투사체 코드 동시 수정은 피하고** PR/브랜치의 소유권을 분리한다.

## 실무 권장 사항

- `W00`은 코드 변경 없는 **현황 조사 전용**으로 유지해 재작성·중복 아키텍처 생성 위험을 줄인다.
- `W03` 완료 후 투사체 경계/풀링 테스트가 통과해야 `W04~W06`를 시작한다.
- `W07`에서 **인벤토리 인스턴스 수와 표시 총기 수**를 구분한다. 손 총은 0° 논리 앵커이나 손에서 떼어 링으로 옮기지 않는다.
- `W09`, `W11`, `W12`는 인벤토리 내부 구현 대신 **확정된 장착 결과 스냅샷을 소비하는 전투 측 Adapter/수치 합성**을 만든다.
- `W13`의 모든 테스트가 통과하기 전에는 전체 Weapon System 완료를 선언하지 않는다.
